# Architecture Documentation

This directory documents the approved architecture for the HR AI Assistant prototype. It describes decisions and intended interfaces only; it does not represent implemented application, database, or infrastructure components.

Start with the [architecture overview](architecture/overview.md), [component diagram](architecture/component-architecture.md), and [assumptions, trade-offs, and open questions](architecture/assumptions-tradeoffs-and-open-questions.md). Durable choices are recorded in [Architecture Decision Records](operations/decision-records/README.md).

The prototype is API-first, uses synthetic data, and runs locally through Docker Compose when implementation begins.
